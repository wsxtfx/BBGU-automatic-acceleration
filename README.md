# BBGU-automatic-acceleration
北部湾大学校园网下载加速

## 环境需要

[NODE.js](https://nodejs.org/zh-cn/download/)

## 使用步骤

分别在/bbgu-campus-auth/config.json内的username和password后填入校园网账号和密码

用node运行/BBGU-automatic acceleration/bbgu-campus-auth/src/main.js
